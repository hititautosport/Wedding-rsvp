# Wedding RSVP

Public RSVP page for the bridal shower and (later) the wedding.

- Shower: https://hititautosport.github.io/Wedding-rsvp/?e=shower
- Wedding: https://hititautosport.github.io/Wedding-rsvp/?e=wedding (shows "not open yet" until `open: true` in `index.html`)

Event details live in the `EVENTS` block at the top of the script in `index.html`.
Answers go to a private table in Supabase; the page can only submit RSVPs, never read them.
